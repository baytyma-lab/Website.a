# ТҰМАР — концепт-сайт бренда казахской национальной одежды

Учебный проект для портфолио. Вымышленный бренд **ТҰМАР** (тұмар — оберег, треугольный амулет):
современная казахская одежда с ручной вышивкой ою-өрнек.

**Демо:** https://baytyma-lab.github.io/tumar/

## Что внутри

- **Главная** — оживлённый первый экран (видео), коллекции, раздел о смысле узоров ою-өрнек, хиты, lookbook, история бренда, отзывы, подписка.
- **Каталог** — 12 товаров, фильтры по категории, размеру, цвету и цене, сортировка, поиск. Состояние фильтров хранится в адресе страницы: ссылку можно переслать, после перезагрузки ничего не сбрасывается.
- **Карточка товара** — галерея, выбор цвета и размера, таблица размеров, блок про узор этой модели, похожие товары.
- **Корзина и избранное** — работают на `localStorage`, переживают перезагрузку. Промокод для теста: `TUMAR10`.

## Как сделано

Без фреймворков и сборки: HTML, CSS и обычный JavaScript. Открывается двойным кликом по `index.html`.

- `js/products.js` — данные каталога, единственный источник правды для всех страниц
- `js/store.js` — корзина и избранное
- `js/ui.js` — шапка, подвал, шторки, модалки, анимации
- `js/catalog.js`, `js/product.js`, `js/home.js` — логика страниц
- `css/style.css` — дизайн-токены и компоненты

## Детали, на которые стоит обратить внимание

- **Шрифты проверены на казахские буквы.** Manrope заявляет поддержку кириллицы, но в нём нет **Ә Ғ Қ Ң Ұ** — это выяснилось замером глифов в браузере. Итоговая пара: Cormorant Garamond и Onest.
- **Контраст посчитан по WCAG.** Акцентные цвета разные для тёмных и светлых секций: ржавчина читается на светлом, охра — на тёмном.
- **Доступность:** навигация с клавиатуры, ловушка фокуса в шторках, `aria`-подписи, цели касания от 44px, поддержка режима «уменьшить анимацию».
- **Адаптив проверен** на 320, 360, 390 и 414px — горизонтального скролла нет.

Фотографии и видео сгенерированы нейросетями специально для этого проекта.
